## List of the best GitHub repositories for free SOC labs and investigative resources

# AtikBagwan00/tryhackme-soc-free-labs:
    Curated list of free TryHackMe rooms, including the Volt Typhoon APT scenario, SIEM (Splunk/ELK) labs, and incident response playbooks.   

        Link: https://github.com/AtikBagwan00/tryhackme-soc-free-labs

# danielgottt/CyberBodega:
    A "master list" of blue team resources featuring links to hands-on platforms, raw forensic artifacts, and infected PCAP samples.

        Link: https://github.com/danielgottt/CyberBodega
# keraattin/Blue-Team-Roadmap:
    A comprehensive step-by-step career guide that aggregates free labs for Windows fundamentals, Active Directory, and network security monitoring.   

        Link: https://github.com/keraattin/Blue-Team-Roadmap

# splunk/botsv3 (and botsv2/botsv1): 
   Official repositories for the Splunk Boss of the SOC datasets, providing gigabytes of real-world logs from sophisticated APT simulations for hunting practice.   

        Link (v3): https://github.com/splunk/botsv3

        Link (v2): https://github.com/splunk/botsv2

# icdfa/soc-training-program: 
    A structured 18-week curriculum including detailed lab guides for packet analysis, Splunk data onboarding, and malware analysis.

        Link: https://github.com/icdfa/soc-training-program

# Lan131/CyGym:
    A simulation framework used to study attacker-defender interactions specifically within the context of the Volt Typhoon APT.

        Link: https://github.com/Lan131/CyGym

# st0pp3r/awesome-soc-analyst:
    A broad aggregation of daily investigative tools, training platforms, and instructional books specifically for the SOC role.   

        Link: https://github.com/st0pp3r/awesome-soc-analyst
